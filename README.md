# 🎯 Number Guessing Game

A simple Python game where the user guesses a number between 1 and 100.

## 🚀 Features
- 3 difficulty levels:
  - Easy (15 attempts)
  - Medium (10 attempts)
  - Hard (5 attempts)
- Random number generation
- Hints (too high / too low)
- Replay option

## 🛠️ Technologies Used
- Python
- Random module

## ▶️ How to Run
1. Open terminal
2. Run:
   python guessing_game.py

## 📌 Description
This project demonstrates loops, conditionals, and user interaction in Python.
